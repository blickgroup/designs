Containment actions Stage 2
  • Quarantine affected stock
  • Recall from customer sites
  • Place supplier hold
  • Document isolation steps taken
Investigation Stage 3
  • Root cause analysis
  • Outcome: pass / fail / inconclusive
  • Approvals workflow (multi-step)
  • Cost tracking and supplier recovery
CAPA actions Resolution
  • Corrective actions with owners + due dates
  • Preventive actions to stop recurrence
  • Customer & supplier communication log

Backend Services
Four Node.js / Express APIs on Fly.io + Cloud Run, all backed by BigQuery
rig-api
Drilling rig configuration CRUD · Fly.io
  • GET /api/rigs — list with search
  • GET /api/rigs/:id — rig + products
  • POST /api/rigs — create configuration
  • PUT /api/rigs/:id — update
  • DEL /api/rigs/:id — soft archive
  • GET /api/[tool-type] — dropdown data
  • GET /api/tools/:id/accessories
operations-api
Health & safety domain · Fly.io
  • POST /api/health-safety/incidents
  • POST /api/health-safety/hazards
  • POST /api/health-safety/vehicle-inspections
  • POST /api/health-safety/training-records
  • GET /api/health-safety/current-user
  • POST /api/health-safety/follow-ups
  • PUT /api/health-safety/follow-ups/:id
compass-api
Workflow & file attachments · Fly.io
  • POST /api/upload-attachment
  • GET /api/ideas — list ideas
  • POST /api/ideas — create idea
  • PUT /api/ideas/:id — update
  • GET /api/deliverables
  • GET /api/goals
copper-api
CRM integration · Cloud Run
  • POST /sync — sync follow-up to Copper
  • PUT /sync/:id — update Copper task status
  • Maps Hub tasks ↔ Copper task fields
  • Two-way status sync
