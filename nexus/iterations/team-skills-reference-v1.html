⚠️ Commonly confused skills — read before choosing
/team-design vs /team-design-studio vs /team-design-heavy
Use /team-design-studio. It proposes UX and produces the spec that build teams consume. /team-design and /team-design-heavy are superseded — studio replaced them for standard features. Heavy remains for regulated/auth/PII features only.
/team-build vs /team-build-lite
Lite = frontend-only. If you need new API routes, DB changes, or background jobs → use /team-build. If the API is already stable and you're only changing UI → use /team-build-lite.
/team-debug vs /team-fix
Debug first, fix second. /team-debug finds the root cause (read-only, no changes). /team-fix implements the solution. Always run debug before fix unless you already know the exact cause.
/team-review vs /team-uat
Review = code audit. UAT = live browser. Review reads files and checks the PR. UAT drives a real browser against production. Both are needed — review before merge, UAT after deploy.

Debug & fix — for bugs, not features
/team-debug
Step 1 of 2
Found a bug but don't know the root cause. Run this first — it investigates. Always runs before /team-fix.
Agents
investigator-frontend (Sonnet) investigator-backend (Sonnet) scribe (Haiku)
Outputs
Root cause identified CHANGELOG draft Memory updates Suggested fix approach
Cannot do
No code changes — read only Does NOT fix the bug
/team-fix
Step 2 of 2
Root cause is known. Implements the fix, runs verify loop until tests pass, then commits and opens a PR. 8-iteration cap.
Agents
backend-dev (Sonnet) frontend-dev (Sonnet) tester (Sonnet) scribe (Haiku) git-publisher (Haiku)
Outputs
Bug fixed + tests passing Trace log (30 min cap) CHANGELOG updated PR to main (no merge)
Cannot do
No merge No deploy Max 8 verify iterations Stops if same failure 3× in a row

/team-uat
Live browser
Feature is deployed. Drives a real browser against production across 3 test layers. Auto-spawns /team-fix if issues found.
Agents

Outputs

Cannot do
No .spec.ts files No dev environment — production only Cannot loop on failure indefinitely Does not deploy
